
# طراحی وب‌سایت هاستینگ با Flexbox

## معرفی پروژه
این پروژه یک قالب کامل و واکنش‌گرا برای وب‌سایت هاستینگ است که با استفاده از **HTML5** و **CSS3** و تمرکز ویژه بر **Flexbox** طراحی شده است.  
هدف پروژه، ایجاد یک ساختار مدرن، سبک و قابل توسعه برای تمرین و تسلط بر Flexbox در طراحی رابط کاربری است.

## ویژگی‌ها
- طراحی کامل صفحهٔ اصلی وب‌سایت هاستینگ  
- استفادهٔ گسترده از Flexbox برای چیدمان بخش‌ها  
- طراحی واکنش‌گرا (Responsive)  
- ساختار کدنویسی تمیز، قابل‌خواندن و قابل‌توسعه  
- مناسب برای تمرین و آموزش Flexbox  

## تکنولوژی‌های استفاده‌شده
- HTML5  
- CSS3  
- Flexbox Layout  
- Git و GitHub برای کنترل نسخه  

## ساختار پوشه‌ها
```
/
├── index.html
├── css/

├── assets/

```

## نحوهٔ استفاده
1. ریپوزیتوری را کلون کنید:
   ```
   git clone https://github.com/seyed-etemadi/Hosting-website-design-using-Flexbox.git
   ```
2. فایل `index.html` را در مرورگر باز کنید.  
3. ساختار و استایل‌ها را بررسی و در صورت نیاز توسعه دهید.

## اهداف پروژه
- تمرین عملی Flexbox  
- ساخت یک قالب UI مناسب برای پروژه‌های واقعی  
- تقویت مهارت‌های طراحی Front-end
